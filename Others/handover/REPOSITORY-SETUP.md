# Repository creation and first upload

Create the repository in the company-approved account or organization:

- Name: `lifecycle-asset-management-v2`
- Description: `Lifecycle Asset Management V2 — Power Apps source, Power Automate workflows, architecture, and step-by-step implementation handovers.`
- Visibility: Private
- Leave initialization with README, .gitignore and license unchecked; the delivery supplies its own README and .gitignore. No open-source license is being assigned to company resources.

Send the resulting repository URL to the main developer. The repository must be accessible to the connected GitHub integration for upload. Upload the contents of the delivery root, so the repository root has Power Apps, Power Automate and Others; avoid an extra github-delivery wrapper folder.

After upload, use the repository commit as the reference for company Claude. Read README.md, Others/handover/START-HERE.md, and the selected app/flow's CLAUDE-HANDOVER.md. Keep runtime configuration and secrets in company systems.
