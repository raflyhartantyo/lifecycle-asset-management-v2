# Baseline knowledge map

Graphify map of the supplied handover plus confirmed disposal scope: 952 nodes, 1,634 relationships, 42 communities. Source paths in graph.json resolve from this repository root. Original source relationships and planned behavior retain their evidence/confidence; this map is not evidence of deployed V2 changes.

Download graph.html and open it in a browser; GitHub displays HTML source rather than hosting it as an app. The viewer loads vis-network from unpkg.com; if company network policy prevents loading that library, use graph.json and the text architecture documents. Graphify CLI can query this graph with `graphify query "<question>" --graph "Others/architecture/knowledge-map/graph.json"`.

The graph is undirected for navigation. Read relationship evidence for operational direction. Host-agent token accounting was unavailable, so no total token-consumption claim is made.
